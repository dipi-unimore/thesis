# Thesis Proposals

### AI, LLMs and Intelligent Systems

* **Enterprise AI Assistant with LLMs, RAG and MCP** — Design and implement a conversational assistant that retrieves information from heterogeneous enterprise sources and invokes external tools through MCP. Evaluate retrieval accuracy, answer quality, latency and tool-use reliability.

* **LLM-based Multi-Agent System** — Design and implement a multi-agent architecture in which specialized LLM-based agents collaborate to solve complex tasks through an orchestration layer and external tools. Compare different agent coordination strategies using a defined set of tasks and evaluation metrics.

* **LLM Watermarking and Robustness Evaluation** — Implement and compare watermarking techniques for detecting LLM-generated text. Measure detectability, impact on text quality and robustness against paraphrasing, rewriting and other transformations.

* **LLM Applications with Spring AI** — Design and implement an AI-powered application using Spring AI and Spring Boot, integrating LLMs, prompt management, structured outputs, tool calling and RAG. Evaluate different integration strategies in terms of functionality, latency and reliability.

* **Benchmarking LLMs for Software Engineering Tasks** — Design and implement a benchmark for systematically evaluating different LLMs on representative Software Engineering tasks, such as code generation, code completion, bug fixing, refactoring, test generation and code explanation. Compare models using standardized datasets and metrics, considering correctness, functional success, code quality, execution time and resource consumption.

* **Workflow Automation and AI Agents with n8n** — Design and implement an automated workflow system using [n8n](https://n8n.io/?utm_source=chatgpt.com) to orchestrate heterogeneous services, APIs and LLM-based components. Investigate different workflow and agent architectures for automating complex tasks, and evaluate reliability, execution time, scalability, maintainability and the degree of human intervention required.

### Digital Twins, IoT and Industrial Systems

* **Industrial Digital Twin with IoT and Machine Learning** — Design and implement a Digital Twin of an industrial cell or MicroFactory by integrating sensor data, machine state information and a simulation model. Add Machine Learning-based anomaly detection and evaluate the system using real or simulated industrial data.

* **Intelligent Microfactory with IoT and Machine Learning** — Implement an end-to-end monitoring pipeline for a MicroFactory, connecting industrial devices through protocols such as MQTT, collecting sensor data and applying Machine Learning for anomaly detection. Evaluate the pipeline in terms of detection accuracy and real-time performance.

* **Manufacturing Execution System for Industrial Production** — Design and implement a MES prototype for managing production orders, machine states and manufacturing operations. Integrate data acquisition and an operational dashboard, and evaluate the system using a simulated or real production workflow.

### Cloud, Microservices and Distributed Systems

* **Design and Evaluation of a Spring-Based Microservices Architecture** — Design and implement a distributed application using Spring Boot and Spring Cloud, decomposing the system into independently deployable microservices. Integrate service discovery, API gateways, inter-service communication, centralized configuration, resilience mechanisms and observability, and evaluate scalability, fault tolerance and performance under different workloads.

* **Cloud-Native IoT Platform with Microservices and Containers** — Design and implement a distributed IoT platform using Spring Boot, Docker and Kubernetes. Evaluate scalability, fault tolerance, deployment complexity and system performance under different workloads.

* **Performance Evaluation of JVMs, JIT/AOT Compilation and Virtual Threads** — Design and implement a systematic benchmark for JVM-based applications, comparing different JVM implementations and execution strategies, including traditional JIT compilation, AOT compilation with GraalVM and Java virtual threads. Evaluate throughput, latency, startup time, memory consumption, scalability and CPU utilization under different workloads, identifying the trade-offs of each approach.

* **Function-as-a-Service Architectures for Event-Driven Applications** — Design and implement an event-driven application using a Function-as-a-Service (FaaS) architecture, deploying independent functions that react to events and interact with managed storage and messaging services. Compare serverless execution with a traditional container-based architecture in terms of scalability, latency, resource utilization, operational complexity and cost.

* **Serverless Event-Driven Pipeline for Data and Image Processing** — Implement an event-driven processing pipeline using AWS Lambda, S3 and DynamoDB. Benchmark execution time, scalability, reliability and resource usage under different workloads.

* **Observability Platform for Distributed Applications** — Integrate OpenTelemetry, Prometheus, Loki and Grafana into a distributed application to collect metrics, logs and traces. Design monitoring dashboards and evaluate the ability to identify performance problems and failures.

### Web, Mobile and Software Engineering

* **Database-Driven Cross-Platform Mobile Application** — Design and implement a mobile application for managing a structured domain such as events, users and registrations, with a backend API and persistent database. Evaluate usability, API performance and data consistency across supported platforms.

* **Mobile Machine Learning with Google ML Kit and AR Frameworks** — Design and implement a mobile application that performs on-device Machine Learning using Google ML Kit, optionally integrating ARCore or Vuforia for augmented-reality features. Evaluate inference accuracy, execution latency, resource consumption and usability on different mobile devices.

* **Interactive 3D Application with Unity** — Design and develop an interactive 3D application using Unity, integrating real-time data, user interaction and an external backend or simulation environment. Evaluate rendering performance, responsiveness and the scalability of the application architecture.

* **Automated UI Testing and CI/CD for Web Applications** — Develop an end-to-end testing suite using Selenium and integrate it into a CI/CD pipeline. Measure test coverage, execution time, failure detection and the effectiveness of automated quality gates.
